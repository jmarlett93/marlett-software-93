sailing Section 01

Sailing simulator

Sailing is a complex physics problem. This simulation uses sailing polar data from the popular Melges 24 class, and a live API of wind direction and velocity from some of my favorite places to sail. I coded an AI auto pilot to plot a course and navigate around racing bouys. You can take over by switching to manual mode.

memory Section 02

Web Worker Threads

We will run an intensive compute function. Experiment A runs on the main thread; experiment B runs in a web worker. Since javascript is single thread, the main thread run will block the UI controls, while the worker run will not.

Responsiveness check

Notice how the clicker cannot increment during experiment A — it queues until the end once the thread is clear. In experiment B, the clicker is not blocked.
